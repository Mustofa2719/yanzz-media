Sering Ditanyakan (FAQ)

Apakah sistem pengerjaan bisa DP terlebih dahulu?

Ya, sangat bisa! Kami menerima sistem DP 50% diawal untuk memulai pengerjaan. Pelunasan sisa 50% dilakukan setelah tugas/website selesai dan Anda cek hasilnya.

Apakah joki tugas saya terjamin rahasia?

100% Dijamin aman! Kami tidak pernah mempublikasikan identitas, nama kampus, maupun file tugas klien. Privasi Anda adalah prioritas utama kami.

Bagaimana jika ada error atau perlu revisi?

Kami menyediakan garansi revisi gratis sampai tugas/website berjalan sesuai dengan brief awal yang disepakati.

Berapa lama proses pembuatan website?

Untuk Landing Page standard membutuhkan waktu 1-2 hari kerja. Sedangkan untuk Company Profile atau Web Custom membutuhkan waktu 3-7 hari kerja tergantung kompleksitas fitur.
